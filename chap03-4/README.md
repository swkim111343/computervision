1. 얕은 복사의 장점, 단점을 쓰시오.
    - 얕은 복사란? -> 주소값만 복사해서 같은 메모리를 공유하는 것
    - 장점 : 빠름, 메모리 절약
    - 단점 : 한쪽 변경시 다른쪽도 영향을받음(독립성 X)

2. 깊은 복사의 장점, 단점을 쓰시오.
    - 깊은 복사란? -> 실제 데이터까지 새로 복사(별도 메모리를 생성)
    - 장점 : 독립적(안전), 한쪽을 변경해도 영향이 없다.
    - 단점 : 속도 느림, 메모리를 더 많이 사용
