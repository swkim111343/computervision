## 실습과제 1
두 점

(Gmin, 0)
(Gmax, 255)

를 지나는 직선의 방정식을 이용한다.

직선의 기본식은

y - y1
──────── = 
x - x1

y2 - y1
────────
x2 - x1

이다.

여기서

x1 = Gmin
y1 = 0

x2 = Gmax
y2 = 255

를 대입하면

y - 0
──────────── = 
x - Gmin

255 - 0
────────────
Gmax - Gmin

즉,

y = (x - Gmin) × 255 / (Gmax - Gmin)

이 된다.

영상에서

x → src(x,y)
y → dst(x,y)

로 바꾸면

dst(x,y)
=
(src(x,y) - Gmin) × 255
──────────────────────
(Gmax - Gmin)

따라서 최종 수식은

dst(x,y)
=
(src(x,y) - Gmin) * 255
──────────────────────
(Gmax - Gmin)

이다.
