## 과제 1 
1. 비주얼 스튜디오 프로젝트 속성에서 Debug 모드, Release 모드의 차이를 설명하라.
    - debug 모드: 디버깅용 개발단계(실행느림), 변수 값 확인, 중단점 사용가능(문제 찾기용)
    -release 모드: 배포용(완성단계), 실행 빠름, 디버깅 어려움(최종 사용자용)

2. 비주얼 스튜디오 프로젝트 속성에서 x86 모드, x64 모드의 차이를 설명하라.
    - x86 (32비트): 메모리 최대 약 4GB 사용, 구형 시스템 호환
    - x64 (64비트): 메모리 거의 제한 없음, 성능 더 좋음, 요즘 기본

3. 빌드 전에 비주얼 스튜디오에서 포함 디렉토리를 설정하는 이유를 설명하라.
    - #include 할 때 헤더파일 찾기 위해
    <pre>#include "opencv2/opencv.hpp"</pre>
    - 컴파일러가 파일을 찾는거를 알려주기 위해 포함디렉터리

4. 빌드 전에 비주얼 스튜디오에서 라이브러리 디렉토리를 설정하는 이유를 설명하라.
    - lib 파일 위치 알려주기
    - 컴파일 끝난후 링커가 라이브러리 찾을 때 사용

5. 빌드 전에 비주얼 스튜디오에서 링커 추가종속성을 설정하는 이유를 설명하라.
    - 이 라이브러리를 쓸거다 라고 명시하는 것
<pre>opencv_world480.lib</pre>
    

6. DLL를 사용하기 위하여 시스템 환경변수 Path에 추가하는 경로는 무엇이고 왜 추가해야 하는지 설명하라.
    - 프로그램 실행할때, .exe는 .dll 필요
    - Windows가 DLL 못 찾으면 실행 실패
<pre>C:\opencv\build\x64\vc16\bin</pre>
