## 컴퓨터비전 챕터04-1 과제
# 실습과제 1
1. API(Application Programming Interface)
    - 응용 프로그램끼리 소통하는 규칙 / 인터페이스
    - 응용 프로그램끼리 소통하는 규칙 / 인터페이스(함수, 클래스, 프로토콜 등의 집합)

2. V4L
    - 리눅스에서 사용하는 영상 장치 제어 API
    - 웹캠, 카메라 같은 영상 장치 다룸

3. FFMPEG
    - 영상/음성 처리 라이브러리 + 도구
    - mp4 → avi 변환, 영상 자르기, 스트리밍 처리와 같은 기능을 함

4. DirectShow
 - 윈도우에서 사용하는 멀티미디어 처리 API
 - 마이크, 카메라, 영상 재생 처리, 필터 기반 구조

5. MSMF
    - DirectShow 후속 윈도우 최신 미디어 API
    - 최신이라 성능 좋음(최신 windows)

6. GStreamer
    - 멀티미디어 처리 프레임워크
