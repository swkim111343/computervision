## 컴퓨터비전 챕터04-2 과제
# 실습과제 1
1. 다음 용어에 대하여 조사하시오.
    - MPEG4 : 동영상과 오디오를 효율적으로 압축하기 위한 국제 표준(낮은 비트레이트에서도 영상 품질 유지, 인터넷 스트리밍, 모바일 영상에 적합, 다양한 코덱 포함 (DivX, Xvid 등))

    - Divx : MPEG-4 기반으로 만든 상용(유료) 영상 코덱(DVD급 화질을 작은 용량으로 압축 가능, 초기 인터넷 영화 공유에서 많이 사용됨, 라이선스 필요)

    - Xvid : DivX에 대응하는 오픈소스 MPEG-4 코덱(무료 사용 가능, DivX와 거의 동일한 성능, 커뮤니티 기반 개발)

    - H264 : MPEG-4 이후 등장한 고효율 영상 압축 표준 (AVC)(MPEG-4보다 훨씬 높은 압축 효율, 고화질(HD, Full HD) 영상 지원, 현재 가장 널리 사용됨)

    - H265 : H.264의 후속, 더 높은 압축 효율 제공(H.264 대비 약 50% 용량 절감, 4K, 8K 영상에 최적화, 계산량 많아서 인코딩 느림)
